Accessibility

We want everyone to be able to use this website and enjoy a visit to the cafe.

This website

We aim to meet the WCAG 2.1 AA standard and keep improving the site as we go.

  • Every menu, button and form can be used with a keyboard.
  • Pages adapt to phones, tablets and desktops.
  • The menu, opening times and contact details are plain text, so screen readers and translation tools can read them.
  • The site still shows its menus, opening times and contact details if JavaScript is turned off.

The cafe

There is step-free access to the main dining area and an accessible toilet. If you have a particular need for your visit, ring us on {{phoneText}} and we'll do what we can to help.

Tell us if something gets in the way

If any part of this website is hard to use, email {{email}} and say which page and what happened. We'll fix it.
